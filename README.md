# NFL Predictor

The goal of this project is to use web scraping and data aggregation to predict the outcomes of NFL games

## Setting up a virtual environment
To instantiate a virtual environment, run the following commands:

`python -m venv venv`

`source venv\bin\activate`

If you are running on powershell, run the below commands
`source Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process`
` .\venv\Scripts\Activate.ps1`

Once that is done, execute:
`pip install -r requirements.txt`
to get the necessary python packages
